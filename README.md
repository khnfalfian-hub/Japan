# Nihongo Journey

Aplikasi belajar bahasa Jepang dari nol dengan tampilan ramah ponsel.

## Isi versi awal
- Materi Hiragana bertahap (7 pelajaran awal)
- Latihan pilihan ganda
- Kamus mini Jepang–Indonesia dengan tombol pengucapan (bergantung dukungan suara browser)
- Progres tersimpan di perangkat menggunakan localStorage
- PWA: dapat ditambahkan ke layar utama dan mendukung cache offline setelah pertama kali dibuka

## Cara mencoba
Buka `index.html` di browser untuk melihat pratinjau. Untuk memasang sebagai aplikasi PWA di Android, unggah seluruh isi folder ini ke hosting HTTPS (misalnya GitHub Pages atau layanan hosting statis), buka alamatnya lewat Chrome Android, lalu pilih menu **Tambahkan ke layar utama / Install app**.

Catatan: ini adalah versi awal PWA, bukan APK native. Instalasi PWA memerlukan HTTPS dan service worker. Materi berikutnya (seluruh Hiragana, Katakana, Kanji, tata bahasa, audio terstruktur, dan JLPT) dapat ditambahkan bertahap.
